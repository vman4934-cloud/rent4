# Сайт аренды инструмента

Next.js 15, TypeScript, Tailwind CSS. Каталог оборудования и приём заявок.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

Сборка:

```bash
npm run build
npm start
```

## Где менять данные

| Что | Файл |
| --- | --- |
| Название, город, телефон, адрес, график, Telegram | `src/data/company.ts` |
| Категории | `src/data/categories.ts` |
| Товары, цены, залоги, наличие, фото | `src/data/products.ts` |
| Минимальный срок и тариф доставки | `src/data/tariffs.ts` |
| Вопросы на главной | `src/data/faq.ts` |

Фотографии всех 45 моделей находятся в `public/products/` и подключены через поле `image`. Источники страниц, адреса изображений и контрольные суммы сохранены в `docs/product-image-sources.json`. Фото показывает модель, а комплектация согласовывается отдельно. Для замены положите новый файл в `public/products/` и обновите поле `image`.

Каталог содержит 45 конкретных моделей из файла «Первая закупка_новая_14.09.2026.xlsx» в 17 категориях. Ставки за сутки предварительные; актуальность подтверждает менеджер. Характеристики пяти моделей дополнены из листа «04 Пилотные модели_3».

Залог и фактическое наличие не указаны в источниках и хранятся как `null` («Уточняется»). Количество к закупке не используется как складской остаток, а стоимость замещения — как залог. Неуточнённые модели, комплекты, внутренняя инфраструктура и закупочные расчёты исключены. Правила отбора и строки источников: `docs/catalog-import.md`.

## Заявки

Обработчик: `src/app/api/inquiry/route.ts`.

Если не заданы переменные окружения, сайт принимает форму в **демонстрационном режиме** и явно пишет, что менеджеру заявка не отправлена.

Скопируйте `.env.example` в `.env.local` и заполните один из каналов:

- Telegram: `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`
- Почта: `SMTP_HOST`, `INQUIRY_EMAIL_TO`, при необходимости `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`, `SMTP_PORT`, `SMTP_SECURE`
- Вебхук: `INQUIRY_WEBHOOK_URL`

Перед реальным приёмом заявок:

1. Замените контакты и юридические данные.
2. Подставьте свои товары и тарифы.
3. Настройте хотя бы один канал доставки заявок.
4. Согласуйте тексты «Условия аренды» и «Политика конфиденциальности».
5. Укажите `NEXT_PUBLIC_SITE_URL`.

Корзина хранится в `localStorage` (`rent4.cart.v1`) и переживает перезагрузку страницы.
