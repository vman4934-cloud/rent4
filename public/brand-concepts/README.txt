RENTGAR — 3 векторных варианта логотипа

01-module / Модуль — графит и лайм, геометрическая монограмма RG.
02-anchor / Опора — оранжевый шестигранник и буква R.
03-cycle / Оборот — синий знак кругового движения, идея аренды.

Файлы без суффикса: все буквы переведены в контуры. Шрифты не нужны.
Файлы -live-text: надпись редактируется как текст; используется Arial Bold.
Файлы -icon: отдельный знак для favicon, аватарки или наклейки.

Adobe Illustrator: Файл → Открыть → выбрать SVG. Знак и надпись находятся
в отдельных группах symbol и wordmark. Для правки узлов используйте Direct
Selection (A), для текста в live-text — Type (T). После открытия можно
сохранить рабочую копию в формате Adobe Illustrator (.ai).

Все изображения векторные, без встроенных растров, со свободно меняемыми
цветами и прозрачным фоном. Текущий логотип сайта не заменён.
